# 06 — Build Phases

## Phase 0 — Repo Bootstrap
Create the project skeleton and baseline tooling.

Expected outputs:
- Next.js app initialized
- TypeScript enabled
- Tailwind configured
- docs folder preserved
- basic README and app routes

## Phase 1 — UX Skeleton
Build the page structure before the full AI pipeline.

Expected outputs:
- landing page
- launcher page
- live session page shell
- review page shell
- dashboard page shell

## Phase 2 — Data Layer
Define schema and types.

Expected outputs:
- session tables
- feedback tables
- vocabulary tables
- TypeScript types
- DB access helpers

## Phase 3 — Session Engine
Implement session creation and live state transitions.

Expected outputs:
- create session flow
- state machine
- pause / resume / end behavior
- basic persistence

## Phase 4 — Voice MVP
Connect voice interaction.

Expected outputs:
- real-time or fallback voice flow
- transcript capture
- basic error handling

## Phase 5 — Review Generation
Turn transcript into structured feedback.

Expected outputs:
- summary generation
- top corrections
- alternative phrasing
- vocabulary extraction

## Phase 6 — Dashboard MVP
Make repeat use visible.

Expected outputs:
- session history
- recurring issues
- expression wall
- trend chart or simple progress view

## Phase 7 — Deployment Hardening
Prepare for public release.

Expected outputs:
- auth or anonymous demo decision implemented
- privacy notice
- empty / error states
- deployment config
- portfolio-friendly landing polish
