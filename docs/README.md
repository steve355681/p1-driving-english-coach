## Purpose
These docs are meant to remove product ambiguity before handing the project to Claude Code or another coding agent.

## Design Boundary
This product is intentionally designed around:
- **before driving** setup
- **during driving** minimal interaction
- **after driving** review and analytics

It is **not** promising full lock-screen assistant behavior, wake-word reliability, or deep CarPlay / Android Auto integration in the MVP.
